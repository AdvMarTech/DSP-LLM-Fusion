# DSP-LLM-Fusion
An innovative framework integrating document structure parsing with LLM-driven information fusion 

## ABSTRACT

Marine accident investigation reports contain rich factual and contextual evidence that is indispensable for maritime safety analysis. To address the automated extraction of structured information from large collections of lengthy marine accident investigation reports with complex text structures, this study proposes an innovative framework integrating document structure parsing with LLM-driven information fusion (DSP-LLM-Fusion). First, it converts PDF reports into JSON layout representations, defines an extraction schema, and parses document structure with confidence annotations. Second, the extraction process is conducted through two complementary branches: table structure-guided extraction for factual and vessel-related fields, and document structure guided paragraph extraction for narrative, causal, and contextual fields. Finally, a confidence fallback fusion strategy resolves conflicting outputs while preserving entity alignment across vessels. Experiments on marine accident investigation reports from the National Transportation Safety Board show that DSP-LLM-Fusion with Qwen2.5-7B-Instruct achieves an Overall-F1 and Avg-field-F1 of 87.08% and an Avg-similarity of 89.70% on an independent test set. Ablation results confirm the contributions of layout parsing, table mapping, paragraph extraction, and confidence fallback fusion. Under the same evaluation protocol, the framework achieves performance comparable to ChatGPT-5.2 and ChatGPT-5.4, while offering greater advantages in local deployment, reproducibility, and privacy preservation.
